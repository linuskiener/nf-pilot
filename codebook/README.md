# Codebook

Version: **v0** (draft, not yet validated)

- `generic_frames.md`: the five generic news frames of Semetko & Valkenburg (2000), with 19 yes/no items
- `epistemic_frames.md`: mode of speech (reporting/opinion/mixed), sourcing, certainty, distrust, propaganda techniques
- `issue_frames.md`: procedure for deriving issue-specific frames inductively (Entman's frame elements, following Matthes & Kohring 2008)

Version every change; the LLM prompts reference codebook versions.
